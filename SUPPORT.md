# Support

**Maintainer:** @tamnd

The site is maintained by the engine team and builds per version from that version's artifacts, so a page always describes the release it is filed under.

## Where to file

- A page that is wrong, missing, unclear, or broken; a dead link; a failing example; site behaviour such as search or navigation: here.
- A generated reference page (one with `generated_from` in its frontmatter) that is wrong: [tamnd/zu](https://github.com/tamnd/zu/issues), because the fix is in the doc comment or the registry entry, not in the page.
- Engine behaviour that the docs describe correctly but you disagree with: [tamnd/zu](https://github.com/tamnd/zu/issues).
- A client's API or install instructions: that client's repository.

Every page carries an "Edit this page" link that resolves to whichever repository owns it, so following it is the reliable way to get this right.

## Security

Documentation issues are handled here. Anything affecting the engine, a client, or a published artifact goes through the single security policy in [tamnd/zu](https://github.com/tamnd/zu/security), never a public issue.
